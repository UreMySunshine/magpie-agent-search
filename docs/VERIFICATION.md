# 验证边界

## Magpie 插件 0.3.0

- Node.js 24.22.0 与 Bun 1.4.4 各通过 184 项离线测试。
- 隔离 Magpie 通过显式工具调用 TinyFish 匿名入口。请求 20 条、配置上限 3 条，返回 3 条公开链接并标记截断。
- 隔离 Magpie 使用模拟响应验证 Querit。无密钥时未发请求。模拟 AnySearch 限流时，原始请求 20 条，AnySearch 请求按协议上限发送 10 条，回退后的 Querit 按配置请求并返回 12 条。显式请求 4 条时返回 4 条。
- TinyFish 带密钥模式和 Querit 的真实账户调用未联网验证。

## Magpie 插件 0.2.0

- Node.js 24.22.0 和 Bun 1.4.4 各通过 175 项离线测试，包含工具参数校验、日期和域名筛选、冷却与 Parallel 会话共享、取消、直连回退和正文截断。
- Magpie 0.1.3901 的隔离网关列出了原生搜索源和两个显式工具。原生 `web_search` 仍能命中 `Agent Search`，请求日志记录状态 200。
- 显式搜索使用匿名 Exa，只保留 `iana.org` 的返回结果。显式读取 `https://example.com/` 返回页面正文，100 字符预算触发截断标记。回环地址返回 `UNSAFE_URL`。
- 日期验证使用模拟的 Tavily 响应，确认日期起点保留、终点排除，并过滤被排除的子域名及日期未知的结果。
- Codex 0.167.2 通过隔离网关发现并执行两个工具。模型回复由本地服务模拟，工具请求使用真实的 Magpie 网关与匿名 Exa。

## Magpie 插件 0.1.0

- Node.js 24.22.0 与 Bun 1.4.4 各通过 169 项离线测试，其中 6 项覆盖插件注册、数量限制、回退、并发冷却、取消和错误脱敏。
- Magpie 0.1.3901 的隔离网关成功注册 `magpie-agent-search:auto`，并验证两个搜索源可以交换顺序。把模拟搜索源移至首位后，网关返回该搜索源的结果。
- 模拟 Tavily 返回 429 后，路由调用 Exa；下一次查询在冷却期间直接调用 Exa。另一次模拟请求达到宿主的 30 秒时限，正在执行的请求收到取消信号，路由未调用下一家。
- 将隔离配置限定为匿名 Exa 后，原生 `web_search` 返回 3 条公开结果。隔离网关的请求日志记录 `Agent Search`、状态 200。此次只对 Exa 执行了联网验证。

## 原技能 0.7.0

0.7.0 的单元测试完全离线，使用 mock transport，不读取用户凭据、不发网络请求。

覆盖八家认证/匿名协议、JSON/SSE、摘要与正文区分、有限回退、Retry-After 与冷却、URL/DNS/重定向安全、错误脱敏、TC3 官方公开签名向量，以及日期/域名边界。使用 `node --test` 运行；结果以 PR 中执行记录为准。

严格日期仅接入 Tavily REST 与 Exa 有 key REST；日期未知时剔除。站点全部本地校验，只有 Tavily/Exa 有 key REST 同时发送服务端域名限制。其他接口不虚构参数。无结果不额外补搜。

历史少量公开请求曾验证部分入口，但不构成持续可用、套餐、计费或搜索质量保证。You 匿名搜索此前超时；AnySearch extract 等路径仅 mock 验证。本次提交未重新运行联网或计费测试。

不随仓库分发历史账户响应、请求 ID、本机网络诊断或实测日志。接口来源见 [SOURCES.md](SOURCES.md)，上游归属见 [UPSTREAM.md](UPSTREAM.md)。
